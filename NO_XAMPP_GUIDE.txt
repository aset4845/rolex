🚀 БЫСТРЫЙ СТАРТ - ВАРИАНТ 1 (Встроенный MySQL)

═══════════════════════════════════════════════════════════════

ШАГ 1: Скачайте phpdesktop
───────────────────────────
https://github.com/cztomczak/phpdesktop/releases


ШАГ 2: Запустите build-standalone.ps1
───────────────────────────────────────
ПКМ → Запустить с PowerShell

Скрипт спросит:
→ Путь к phpdesktop (укажите или Enter)
→ MySQL опции:
  1 = Взять из XAMPP (по умолчанию)
  2 = Взять MariaDB portable
  3 = SQLite (без MySQL)


ШАГ 3: Дождитесь сборки
───────────────────────────
Создастся: C:\RolexShop-Standalone\


ШАГ 4: Тестирование
───────────────────────────
1. Откройте: C:\RolexShop-Standalone\
2. Запустите: Start.bat (НЕ RolexShop.exe!)
3. MySQL запустится автоматически
4. Откроется приложение

⚙️ КАК ЭТО РАБОТАЕТ

═══════════════════════════════════════════════════════════════

1. Пользователь запускает Start.bat

2. Start.bat запускает MySQL:
   mysql\bin\mysqld.exe --defaults-file=mysql\my.ini

3. Ждет 3 секунды

4. Запускает RolexShop.exe

5. Приложение подключается к MySQL на порту 3307

6. Все работает БЕЗ XAMPP!


═══════════════════════════════════════════════════════════════

🔧 ПЕРВЫЙ ЗАПУСК

═══════════════════════════════════════════════════════════════

При первом запуске откроется мастер установки.

Используйте эти настройки:

  Host: 127.0.0.1
  Port: 3307          ← ВАЖНО! 3307, не 3306
  Database: rolex_db
  User: root
  Password: (пусто)

📦 РАСПРОСТРАНЕНИЕ

═══════════════════════════════════════════════════════════════

Для пользователей:

1. Заархивируйте C:\RolexShop-Standalone\ в ZIP

2. Или создайте установщик с Inno Setup

3. Пользователь:
   - Распаковывает
   - Запускает Start.bat
   - Готово!

НЕ НУЖНО:
- ❌ Устанавливать XAMPP
- ❌ Устанавливать MySQL
- ❌ Настраивать сервер
- ❌ Что-то конфигурировать


═══════════════════════════════════════════════════════════════

⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

═══════════════════════════════════════════════════════════════

1. ВСЕГДА запускайте через Start.bat
   НЕ запускайте RolexShop.exe напрямую!

2. Для остановки используйте Stop.bat
   Или просто закройте приложение

3. База данных в: mysql\data\rolex_db\

4. Порт MySQL: 3307 (не 3306!)

5. Размер приложения: ~250-350 МБ

🛠️ НАСТРОЙКА Database.php

═══════════════════════════════════════════════════════════════

Для standalone версии нужно изменить порт в Database.php:

<?php
class Database {
    private $host = '127.0.0.1';
    private $port = 3307;        // ← Изменено с 3306!
    private $db_name = 'rolex_db';
    private $username = 'root';
    private $password = '';
    // ...
}

🆘 TROUBLESHOOTING

═══════════════════════════════════════════════════════════════

Проблема: MySQL не запускается
Решение:
  - Запустите Start.bat от администратора
  - Проверьте mysql\data\ существует
  - Посмотрите debug.log

Проблема: Порт 3307 занят
Решение:
  - Измените порт в mysql\my.ini
  - Измените порт в Database.php

Проблема: Приложение не подключается к БД
Решение:
  - Убедитесь что запускаете Start.bat
  - Проверьте что MySQL запустился (см. консоль)
  - Используйте порт 3307 в настройках
