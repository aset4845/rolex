Автоматическая загрузка phpdesktop заблокирована.
Следуйте этим ПРОСТЫМ шагам:

═══════════════════════════════════════════════════════════════

ШАГ 1: СКАЧАЙТЕ PHPDESKTOP ВРУЧНУЮ

═══════════════════════════════════════════════════════════════

1. Откройте в браузере:
   https://github.com/cztomczak/phpdesktop/releases

2. Найдите релиз "chrome-v57.0-final"

3. Скачайте файл:
   phpdesktop-chrome-57.0-rc-php-7.1.3.zip
   (размер ~82 МБ)

4. Сохраните где удобно, например:
   C:\Downloads\phpdesktop-chrome-57.0-rc-php-7.1.3.zip


═══════════════════════════════════════════════════════════════

ШАГ 2: РАСПАКУЙТЕ

═══════════════════════════════════════════════════════════════

1. ПКМ на скачанном файле → Извлечь все

2. Распакуйте в:
   C:\phpdesktop-chrome-v57.0-rc-php-7.1.3\

   Структура должна быть:
   C:\phpdesktop-chrome-v57.0-rc-php-7.1.3\
   ├── phpdesktop-chrome.exe
   ├── settings.json
   ├── php\
   └── www\


═══════════════════════════════════════════════════════════════

ШАГ 3: ЗАПУСТИТЕ СБОРКУ

═══════════════════════════════════════════════════════════════

Теперь у вас есть phpdesktop!

Запустите ОДИН из скриптов:

┌─────────────────────────────────────────────────────────────┐
│ ВАРИАНТ А: build-standalone.ps1 (интерактивный)            │
└─────────────────────────────────────────────────────────────┘

ПКМ на build-standalone.ps1 → Запустить с PowerShell

Скрипт спросит:
→ Путь к phpdesktop: C:\phpdesktop-chrome-v57.0-rc-php-7.1.3
→ MySQL откуда: 1 (из XAMPP)


┌─────────────────────────────────────────────────────────────┐
│ ВАРИАНТ Б: Команда PowerShell (автоматический)             │
└─────────────────────────────────────────────────────────────┘

Откройте PowerShell и выполните:

cd c:\xampp\htdocs\rolex

$env:PHPDESKTOP_PATH="C:\phpdesktop-chrome-v57.0-rc-php-7.1.3"
$env:MYSQL_PATH="C:\xampp\mysql"
$env:OUTPUT_PATH="C:\RolexShop-Standalone"

.\build-standalone.ps1


═══════════════════════════════════════════════════════════════

ШАГ 4: ГОТОВО!

═══════════════════════════════════════════════════════════════

После завершения сборки:

Приложение будет в: C:\RolexShop-Standalone\

Запустите: C:\RolexShop-Standalone\Start.bat

Используйте настройки:
  Host: 127.0.0.1
  Port: 3307
  Database: rolex_db
  User: root
  Password: (пусто)


═══════════════════════════════════════════════════════════════

АЛЬТЕРНАТИВА: БЫСТРАЯ РУЧНАЯ СБОРКА

═══════════════════════════════════════════════════════════════

Если скрипты не работают, соберите вручную:

1. Создайте папку: C:\RolexShop-Standalone\

2. Скопируйте ВСЕ файлы из phpdesktop в эту папку

3. Скопируйте папку c:\xampp\mysql\ в C:\RolexShop-Standalone\mysql\

4. Очистите C:\RolexShop-Standalone\www\

5. Скопируйте ВСЕ файлы проекта в www\:
   c:\xampp\htdocs\rolex\admin\    → www\admin\
   c:\xampp\htdocs\rolex\app\      → www\app\
   c:\xampp\htdocs\rolex\public\   → www\public\
   и т.д.

6. Создайте файл Start.bat (см. ниже)

7. Переименуйте phpdesktop-chrome.exe → RolexShop.exe


═══════════════════════════════════════════════════════════════

START.BAT СОДЕРЖИМОЕ:

═══════════════════════════════════════════════════════════════

@echo off
cd /d "%~dp0"
echo Starting MySQL...
start /B mysql\bin\mysqld.exe --defaults-file=mysql\my.ini --standalone
timeout /t 3 /nobreak >nul
echo Starting Rolex Shop...
start RolexShop.exe
pause


═══════════════════════════════════════════════════════════════

MYSQL\MY.INI СОДЕРЖИМОЕ:

═══════════════════════════════════════════════════════════════

[mysqld]
datadir=mysql/data
port=3307
basedir=mysql
character-set-server=utf8mb4
collation-server=utf8mb4_unicode_ci
skip-networking
enable-named-pipe

[client]
port=3307
