====================================================================
     ROLEX SHOP - Упаковка в exe с phpdesktop-chrome
====================================================================

ПРОБЛЕМА С КОДИРОВКОЙ ИСПРАВЛЕНА!

Доступны 3 способа упаковки проекта:

--------------------------------------------------------------------
СПОСОБ 1: PowerShell скрипт (РЕКОМЕНДУЕТСЯ)
--------------------------------------------------------------------

Файл: build-package.ps1

Как запустить:
1. Щелкните правой кнопкой по build-package.ps1
2. Выберите "Запустить с помощью PowerShell"

Преимущества:
+ Нет проблем с кодировкой
+ Интерактивный выбор пути
+ Цветной вывод
+ Проверка ошибок


--------------------------------------------------------------------
СПОСОБ 2: Упрощенный BAT скрипт
--------------------------------------------------------------------

Файл: build-simple.bat

Как запустить:
Дважды кликните по build-simple.bat

Преимущества:
+ Запрашивает путь к phpdesktop
+ Простой и понятный
+ Пошаговые сообщения


--------------------------------------------------------------------
СПОСОБ 3: Автоматический BAT скрипт
--------------------------------------------------------------------

Файл: build-package.bat

Перед запуском:
1. Откройте build-package.bat в текстовом редакторе
2. На строке 6 измените путь:
   set PHPDESKTOP_PATH=C:\ваш\путь\к\phpdesktop
3. Сохраните и запустите


====================================================================
БЫСТРЫЙ СТАРТ
====================================================================

1. Скачайте phpdesktop:
   https://github.com/cztomczak/phpdesktop/releases

2. Распакуйте в любую папку

3. Запустите build-package.ps1 (PowerShell)
   ИЛИ build-simple.bat

4. Следуйте инструкциям на экране

5. Готово! Приложение в C:\RolexShop-Portable\


====================================================================
ЧТО ДЕЛАТЬ ДАЛЬШЕ
====================================================================

1. Экспортируйте базу данных:
   c:\xampp\mysql\bin\mysqldump -u root -p rolex_db > install.sql

2. Скопируйте install.sql в:
   C:\RolexShop-Portable\www\database\install.sql

3. Протестируйте:
   Запустите C:\RolexShop-Portable\RolexShop.exe
