ОСНОВНЫЕ ФАЙЛЫ (для упаковки)
====================================================================

[1] build-package.ps1
    PowerShell скрипт для автоматической упаковки
    РЕКОМЕНДУЕТСЯ - нет проблем с кодировкой
    Запуск: ПКМ → "Запустить с помощью PowerShell"

[2] build-simple.bat
    Упрощенный BAT скрипт с интерактивным выбором пути
    Запуск: Двойной клик

[3] build-package.bat
    Автоматический BAT скрипт (требует настройки пути)
    Запуск: Двойной клик после редактирования

[4] phpdesktop-settings.json
    Конфигурационный файл для phpdesktop-chrome
    Содержит настройки окна, порта, веб-сервера

[5] install.php
    Красивый мастер установки базы данных
    Запускается автоматически при первом запуске

[6] installer-script.iss
    Скрипт Inno Setup для создания установщика
    Используется для создания Setup.exe

КАК ИСПОЛЬЗОВАТЬ
====================================================================

БЫСТРЫЙ СТАРТ (3 шага):

1. Скачайте phpdesktop-chrome:
   https://github.com/cztomczak/phpdesktop/releases

2. Запустите build-package.ps1 (ПКМ → Запустить с PowerShell)

3. Готово! Приложение в C:\RolexShop-Portable\


ПОДРОБНАЯ ИНСТРУКЦИЯ:

1. Откройте файл: BUILD_INSTRUCTIONS.md
   (Или packaging-guide.html в браузере)

2. Следуйте пошаговым инструкциям

3. При проблемах смотрите раздел "Troubleshooting"


====================================================================
РЕКОМЕНДУЕМЫЙ ПОРЯДОК ДЕЙСТВИЙ
====================================================================

ШАГ 1: Подготовка
□ Скачать phpdesktop-chrome
□ Распаковать в удобную папку
□ Запомнить путь к phpdesktop

ШАГ 2: Упаковка
□ Запустить build-package.ps1
□ Указать путь к phpdesktop (или Enter для пути по умолчанию)
□ Дождаться завершения

ШАГ 3: База данных
□ Экспортировать БД: mysqldump -u root -p rolex_db > install.sql
□ Скопировать install.sql в C:\RolexShop-Portable\www\database\

ШАГ 4: Тестирование
□ Запустить C:\RolexShop-Portable\RolexShop.exe
□ Пройти мастер установки
□ Проверить все функции

ШАГ 5: Распространение (опционально)
□ Для теста: заархивировать в ZIP
□ Для пользователей: создать установщик с Inno Setup

РАЗМЕРЫ И ТРЕБОВАНИЯ
====================================================================

Размер готового приложения:
- Минимальный пакет: ~100-150 МБ
- С изображениями: ~150-200 МБ
- После установки: ~200-300 МБ

Требования на компьютере пользователя:
- Windows 7 или выше
- MySQL сервер (нужно установить отдельно)
- ~500 МБ свободного места


====================================================================
ЧАСТЫЕ ВОПРОСЫ
====================================================================

Q: Где будет создано приложение?
A: В папке C:\RolexShop-Portable\

Q: Нужен ли MySQL в приложении?
A: Нет, пользователь должен установить MySQL отдельно

Q: Как изменить название приложения?
A: Отредактируйте settings.json после упаковки

Q: Можно ли включить MySQL в пакет?
A: Да, но это усложнит процесс. См. PHPDESKTOP_PACKAGING.md

Q: Как создать установщик?
A: Используйте Inno Setup и файл installer-script.iss
