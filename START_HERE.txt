  БЫСТРЫЙ СТАРТ (для тех кто спешит)
═══════════════════════════════════════════════════════════════

  1. Скачайте phpdesktop:
     https://github.com/cztomczak/phpdesktop/releases
     Файл: phpdesktop-chrome-v57.0-rc-php-7.1.3.zip

  2. Распакуйте в любую папку

  3. Запустите: build-fixed.ps1
     (ПКМ → Запустить с PowerShell)

  4. ПЕРЕД запуском приложения:
     → Запустите MySQL в XAMPP Control Panel
     → Дождитесь зеленого индикатора

  5. Запустите: C:\RolexShop-Portable\RolexShop.exe

  ГОТОВО!

═══════════════════════════════════════════════════════════════
  ВАЖНО! ЧАСТЫЕ ОШИБКИ
═══════════════════════════════════════════════════════════════

  ❌ ОШИБКА: "Подключение не установлено"
     ✅ РЕШЕНИЕ: Запустите MySQL в XAMPP перед запуском app

  ❌ ОШИБКА: "404 Not Found"
     ✅ РЕШЕНИЕ: Проверьте структуру папок (см. URGENT_FIX.txt)

  ❌ ОШИБКА: Файлы в www\rolex\ вместо www\
     ✅ РЕШЕНИЕ: Используйте build-fixed.ps1

  ❌ ОШИБКА: Порт 54007 занят
     ✅ РЕШЕНИЕ: Измените порт в settings.json


═══════════════════════════════════════════════════════════════
  ПРАВИЛЬНАЯ СТРУКТУРА
═══════════════════════════════════════════════════════════════

  После сборки должно быть ТАК:

  C:\RolexShop-Portable\
  ├── RolexShop.exe
  ├── settings.json
  ├── php\
  └── www\
      ├── index.php      ← ЗДЕСЬ!
      ├── install.php
      ├── admin\
      ├── public\
      ├── app\
      └── database\

  НЕ ДОЛЖНО быть:
  www\rolex\index.php    ← ЭТО НЕПРАВИЛЬНО!


═══════════════════════════════════════════════════════════════
  ПОРЯДОК ДЕЙСТВИЙ
═══════════════════════════════════════════════════════════════

  [ ] 1. Скачать и распаковать phpdesktop

  [ ] 2. Запустить build-fixed.ps1

  [ ] 3. Дождаться завершения сборки

  [ ] 4. Экспортировать базу данных:
        cd c:\xampp\mysql\bin
        mysqldump -u root -p rolex_db > install.sql

  [ ] 5. Скопировать install.sql в:
        C:\RolexShop-Portable\www\database\

  [ ] 6. ЗАПУСТИТЬ MySQL В XAMPP!

  [ ] 7. Запустить RolexShop.exe

  [ ] 8. Пройти мастер установки


═══════════════════════════════════════════════════════════════
  ПОСЛЕ УСПЕШНОЙ УПАКОВКИ
═══════════════════════════════════════════════════════════════

  Для тестирования:
    Заархивируйте C:\RolexShop-Portable\ в ZIP

  Для пользователей:
    1. Скачайте Inno Setup
    2. Откройте installer-script.iss
    3. Build → Compile
    4. Готовый установщик в папке installer-output\
