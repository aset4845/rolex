# Инструкция по сборке Rolex Shop в exe-файл

## Проблема с кодировкой решена!

Создано 3 варианта скриптов упаковки. Выберите наиболее удобный:

---

## Вариант 1: PowerShell (РЕКОМЕНДУЕТСЯ)

### Преимущества:
- Лучше работает с путями
- Цветной вывод
- Подробные сообщения
- Нет проблем с кодировкой

### Как запустить:

1. Щелкните правой кнопкой по файлу `build-package.ps1`
2. Выберите "Запустить с помощью PowerShell"

ИЛИ откройте PowerShell и выполните:
```powershell
cd c:\xampp\htdocs\rolex
powershell -ExecutionPolicy Bypass -File build-package.ps1
```

---

## Вариант 2: Упрощенный BAT (build-simple.bat)

### Преимущества:
- Запрашивает путь к phpdesktop
- Пошаговые сообщения
- Проверка ошибок

### Как запустить:

Просто дважды кликните по файлу `build-simple.bat`

---

## Вариант 3: Автоматический BAT (build-package.bat)

### Для использования:

1. Откройте файл `build-package.bat` в текстовом редакторе
2. Исправьте путь к phpdesktop на строке 6:
   ```batch
   set PHPDESKTOP_PATH=C:\phpdesktop-chrome-v57.0-rc-php-7.1.3
   ```
   Замените на свой путь, например:
   ```batch
   set PHPDESKTOP_PATH=C:\Users\YourName\Downloads\phpdesktop
   ```
3. Сохраните и запустите

---

## Пошаговая инструкция

### Шаг 1: Скачайте phpdesktop

1. Перейдите на https://github.com/cztomczak/phpdesktop/releases
2. Скачайте последнюю версию, например:
   - `phpdesktop-chrome-v57.0-rc-php-7.1.3.zip` (рекомендуется)
   - или `phpdesktop-chrome-v57.0-rc-php-5.4.45.zip`

3. Распакуйте в удобное место, например:
   - `C:\phpdesktop-chrome-v57.0-rc-php-7.1.3\`
   - `C:\Users\YourName\Downloads\phpdesktop\`

### Шаг 2: Запустите скрипт упаковки

**Рекомендуется PowerShell:**
```powershell
powershell -ExecutionPolicy Bypass -File build-package.ps1
```

Скрипт попросит указать путь к phpdesktop. Введите путь или нажмите Enter для пути по умолчанию.

### Шаг 3: Экспортируйте базу данных

Откройте командную строку и выполните:

```bash
cd c:\xampp\mysql\bin
mysqldump -u root -p rolex_db > install.sql
```

Введите пароль MySQL (обычно пустой, просто нажмите Enter).

### Шаг 4: Скопируйте SQL дамп

Скопируйте файл `install.sql` в:
```
C:\RolexShop-Portable\www\database\install.sql
```

### Шаг 5: Тестирование

1. Перейдите в `C:\RolexShop-Portable\`
2. Запустите `RolexShop.exe` или `Start.bat`
3. Должен открыться установщик приложения
4. Следуйте инструкциям мастера установки

### Шаг 6: Настройка при первом запуске

При первом запуске:
1. Убедитесь что MySQL запущен (XAMPP Control Panel > MySQL > Start)
2. В мастере установки введите:
   - Хост: `localhost`
   - Порт: `3306`
   - База данных: `rolex_db`
   - Пользователь: `root`
   - Пароль: (ваш пароль MySQL или пусто)
3. Нажмите "Установить"

## Распространение приложения

### Для тестирования:
Просто заархивируйте папку `C:\RolexShop-Portable\` в ZIP

### Для пользователей:
Создайте установщик с Inno Setup:

1. Скачайте Inno Setup: https://jrsoftware.org/isdl.php
2. Установите Inno Setup
3. Откройте файл `installer-script.iss`
4. Исправьте путь на строке 56:
   ```
   Source: "C:\RolexShop-Portable\*"; DestDir: "{app}"; ...
   ```
5. Build > Compile
6. Готовый установщик будет в папке `installer-output\`

## Частые проблемы

### Проблема: "phpdesktop not found"
**Решение:** Убедитесь что путь к phpdesktop правильный и там есть файл `phpdesktop-chrome.exe`

### Проблема: Ошибки кодировки в bat-файле
**Решение:** Используйте PowerShell скрипт (`build-package.ps1`) вместо bat-файлов

### Проблема: "MySQL not found" при установке
**Решение:**
1. Запустите MySQL через XAMPP Control Panel
2. Или установите MySQL отдельно
3. Или используйте SQLite (потребуется модификация кода)

### Проблема: Приложение не запускается
**Решение:**
1. Проверьте файл `debug.log` в корне приложения
2. Запустите от имени администратора
3. Убедитесь что порт 54007 свободен

### Проблема: База данных не подключается
**Решение:**
1. Проверьте что MySQL запущен
2. Проверьте данные в `www\app\Config\Database.php`
3. Убедитесь что база `rolex_db` создана
4. Проверьте логин/пароль MySQL

## Настройка приложения

### Изменить название окна:
Отредактируйте `settings.json`:
```json
"main_window": {
    "title": "Ваше название"
}
```

### Изменить порт:
```json
"application": {
    "main_url": "http://127.0.0.1:YOUR_PORT/index.php",
    "web_server": "127.0.0.1:YOUR_PORT"
}
```

### Изменить размер окна:
```json
"main_window": {
    "default_size": [1400, 900]
}
```
