Rolex Shop

Руководство по упаковке в exe-файл с phpdesktop-chrome

Введение

Это руководство поможет вам упаковать ваш PHP проект Rolex Shop в standalone exe-приложение, которое можно запускать на Windows без установки веб-сервера.

Проблема с кодировкой решена! Доступны 3 способа упаковки, включая PowerShell скрипт без проблем с кодировкой.

Способы упаковки

Способ 1: PowerShell скрипт РЕКОМЕНДУЕТСЯ

Файл: build-package.ps1

Преимущества:

  • Нет проблем с кодировкой
  • Интерактивный выбор пути
  • Цветной вывод с индикацией прогресса
  • Автоматическая проверка ошибок

Как запустить:

  1. Щелкните правой кнопкой по файлу build-package.ps1
  2. Выберите "Запустить с помощью PowerShell"
  3. Следуйте инструкциям на экране

Или через командную строку:

powershell -ExecutionPolicy Bypass -File build-package.ps1

Способ 2: Упрощенный BAT скрипт

Файл: build-simple.bat

Преимущества:

  • Простой в использовании
  • Запрашивает путь к phpdesktop
  • Пошаговые сообщения

Как запустить:

Просто дважды кликните по файлу build-simple.bat

Способ 3: Автоматический BAT скрипт

Файл: build-package.bat

Перед использованием:

  1. Откройте файл в текстовом редакторе
  2. На строке 6 измените путь к phpdesktop
  3. Сохраните и запустите

Пошаговая инструкция

  1. Скачайте phpdesktop-chrome

    Перейдите на GitHub Releases

    Скачайте последнюю версию, например:

    phpdesktop-chrome-v57.0-rc-php-7.1.3.zip
  2. Распакуйте phpdesktop

    Распакуйте архив в любую удобную папку, например:

    C:\phpdesktop-chrome-v57.0-rc-php-7.1.3\
  3. Запустите скрипт упаковки

    Используйте один из трех способов (рекомендуется PowerShell)

    Скрипт запросит путь к phpdesktop или использует путь по умолчанию

  4. Экспортируйте базу данных

    Откройте командную строку и выполните:

    cd c:\xampp\mysql\bin mysqldump -u root -p rolex_db > install.sql

    Введите пароль MySQL (обычно пустой - просто нажмите Enter)

  5. Скопируйте SQL дамп

    Скопируйте файл install.sql в:

    C:\RolexShop-Portable\www\database\install.sql
  6. Тестирование

    Запустите:

    C:\RolexShop-Portable\RolexShop.exe

    Или двойным кликом по Start.bat

  7. Первичная настройка

    При первом запуске откроется мастер установки:

    • Хост: localhost
    • Порт: 3306
    • База данных: rolex_db
    • Пользователь: root
    • Пароль: (ваш пароль или пусто)

Распространение

Для тестирования:

Просто заархивируйте папку C:\RolexShop-Portable\ в ZIP-архив

Для конечных пользователей:

Создайте профессиональный установщик с Inno Setup:

  1. Скачайте Inno Setup
  2. Откройте файл installer-script.iss
  3. Исправьте путь к собранному приложению (строка 56)
  4. Build → Compile
  5. Готовый установщик будет в папке installer-output\

Часто задаваемые вопросы

Проблема Решение
Ошибки кодировки в BAT-файле Используйте PowerShell скрипт build-package.ps1
"phpdesktop not found" Проверьте путь к phpdesktop и наличие файла phpdesktop-chrome.exe
Приложение не запускается Проверьте debug.log, запустите от администратора
Не подключается к базе данных Убедитесь что MySQL запущен, проверьте данные подключения
Порт 54007 занят Измените порт в settings.json

Дополнительная информация

Размеры приложения:
Базовый пакет: ~100-150 МБ
С изображениями: ~150-200 МБ
После установки: ~200-300 МБ
Важно: Приложение НЕ включает MySQL сервер. Пользователям потребуется установить MySQL отдельно или использовать существующий сервер.
