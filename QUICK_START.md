# Быстрый старт: Упаковка Rolex Shop в exe

## Минимальные шаги для создания exe-приложения

### 1. Скачайте phpdesktop-chrome
```
https://github.com/cztomczak/phpdesktop/releases
```
Скачайте последнюю версию (например, phpdesktop-chrome-v57.0-rc-php-7.1.3.zip)

### 2. Распакуйте и настройте путь
Распакуйте в `C:\phpdesktop-chrome-v57.0-rc-php-7.1.3\`

Откройте файл `build-package.bat` и убедитесь что путь правильный:
```batch
set PHPDESKTOP_PATH=C:\phpdesktop-chrome-v57.0-rc-php-7.1.3
```

### 3. Экспортируйте базу данных
```bash
# В командной строке MySQL или phpMyAdmin
mysqldump -u root -p rolex_db > install.sql
```

Сохраните файл `install.sql` - он понадобится позже.

### 4. Запустите упаковку
Дважды кликните по `build-package.bat`

Скрипт автоматически:
- Создаст папку `C:\RolexShop-Portable\`
- Скопирует все файлы phpdesktop
- Скопирует ваш проект
- Настроит конфигурацию
- Переименует exe в `RolexShop.exe`

### 5. Добавьте базу данных
Скопируйте ваш файл `install.sql` в:
```
C:\RolexShop-Portable\www\database\install.sql
```

### 6. Тестирование
Запустите `C:\RolexShop-Portable\RolexShop.exe`

При первом запуске:
1. Откроется окно установки
2. Следуйте инструкциям мастера
3. Введите данные MySQL сервера
4. Дождитесь завершения установки

### 7. Распространение

#### Вариант А: ZIP-архив (для тестирования)
Просто заархивируйте папку `C:\RolexShop-Portable\` в zip

#### Вариант Б: Установщик (рекомендуется)
1. Скачайте Inno Setup: https://jrsoftware.org/isdl.php
2. Откройте `installer-script.iss` в Inno Setup
3. Нажмите Build > Compile
4. Готовый установщик будет в папке `installer-output\`

## Важные замечания

### База данных
Приложение НЕ включает MySQL сервер. Пользователям нужно:
1. Установить MySQL на своем компьютере
2. Запустить MySQL сервер
3. Запустить RolexShop.exe
4. Пройти мастер установки

### Альтернатива: Полностью portable решение
Если нужно приложение без внешних зависимостей:
1. Добавьте portable MySQL (MariaDB)
2. Создайте `start.bat` который запускает MySQL, затем приложение
3. Конвертируйте базу в SQLite (изменится код приложения)

### Размеры
- Минимальный пакет (без MySQL): ~100-150 МБ
- С portable MySQL: ~250-350 МБ
- После установки: ~300-500 МБ (с данными)

## Troubleshooting

### Ошибка: "Не удается подключиться к базе данных"
✓ Убедитесь что MySQL запущен
✓ Проверьте данные подключения в `www/app/Config/Database.php`
✓ Убедитесь что база данных создана

### Ошибка: "Порт 54007 занят"
✓ Измените порт в `settings.json`:
```json
"web_server": "127.0.0.1:54008"
```

### Приложение не запускается
✓ Проверьте `debug.log` в корне приложения
✓ Убедитесь что все файлы скопированы
✓ Попробуйте запустить от имени администратора

## Дополнительная настройка

### Изменение названия окна
Отредактируйте `settings.json`:
```json
"main_window": {
    "title": "Ваше название"
}
```

### Изменение размера окна
```json
"default_size": [1400, 900]
```

### Отключение debug логов
```json
"debugging": {
    "show_console": false,
    "log_level": "ERROR"
}
```
