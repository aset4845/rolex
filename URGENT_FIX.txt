Ошибка:
  "Подключение не установлено, т.к. конечный компьютер
   отверг запрос на подключение"

РЕШЕНИЕ:

  1. Откройте XAMPP Control Panel

  2. Найдите строку "MySQL"

  3. Нажмите кнопку "Start"

  4. Дождитесь ЗЕЛЕНОГО индикатора

  5. ТОЛЬКО ПОСЛЕ ЭТОГО запускайте RolexShop.exe


┌────────────────────────────────────────────────────────────────┐
│ ПРОБЛЕМА 2: НЕПРАВИЛЬНАЯ СТРУКТУРА ПАПОК                      │
└────────────────────────────────────────────────────────────────┘

Ошибка:
  C:\RolexShop-Portable\www\rolex\app\...
                            ^^^^^^
                         ЛИШНЯЯ ПАПКА!

Должно быть:
  C:\RolexShop-Portable\www\app\...
  C:\RolexShop-Portable\www\admin\...
  C:\RolexShop-Portable\www\public\...

БЫСТРОЕ РЕШЕНИЕ:

  Вариант А: Пересобрать правильно
  ═════════════════════════════════

  1. Запустите: build-fixed.ps1
     (ПКМ -> Запустить с PowerShell)

  2. Готово!


  Вариант Б: Исправить вручную
  ═════════════════════════════════

  1. Откройте: C:\RolexShop-Portable\www\

  2. Если есть папка "rolex":
     - Зайдите в нее
     - ВЫРЕЖЬТЕ все файлы (Ctrl+X)
     - Вернитесь в www\
     - ВСТАВЬТЕ файлы (Ctrl+V)
     - Удалите пустую папку "rolex"

  3. Проверьте структуру:

     www\
     ├── index.php       ← Должен быть ЗДЕСЬ!
     ├── install.php
     ├── admin\
     ├── public\
     ├── app\
     └── uploads\


┌────────────────────────────────────────────────────────────────┐
│ ПРАВИЛЬНЫЙ ПОРЯДОК ЗАПУСКА                                     │
└────────────────────────────────────────────────────────────────┘

  ШАГ 1: Запустите MySQL
  ═══════════════════════
    XAMPP Control Panel → MySQL → Start
    Дождитесь зеленого цвета


  ШАГ 2: Проверьте структуру папок
  ═════════════════════════════════
    C:\RolexShop-Portable\www\index.php должен существовать
    НЕ должно быть: www\rolex\index.php


  ШАГ 3: Запустите приложение
  ════════════════════════════
    C:\RolexShop-Portable\RolexShop.exe


  ШАГ 4: В мастере установки
  ═══════════════════════════
    Host: localhost
    Port: 3306
    Database: rolex_db
    User: root
    Password: (пусто или ваш пароль)

  ✓ Файл существует:

  ✓ Файл существует:
    C:\RolexShop-Portable\www\app\Config\Database.php

     cd c:\xampp\mysql\bin
     mysql -u root -p
